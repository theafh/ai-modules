# knowledge-management

A plugin for building and maintaining a persistent, compounding knowledge base of interlinked plain markdown files.

## Skills

- **wiki** — Build and maintain a personal/team wiki: ingest sources (URLs, articles, papers, PDFs, transcripts, pastes), query the wiki, lint/audit, archive, reorganise. Use when the user asks to create, build, ingest into, query, or maintain their wiki / knowledge base / research notes.
