# Let a wiki declare in-repo source roots for `sources:`

## Goal

A wiki whose primary source is a live document tracked in the same repository can cite that document's files in `sources:` frontmatter, structured and lint-validated, without capturing them into `raw/`. The wiki declares each such root once in `SCHEMA.md`; bound and acknowledged-channel reporting follow **Honour it in `check_source_paths_exist`.**; and the `auto_shaper_wiki` agent honours the declaration instead of migrating those entries to `## Derived from`. A wiki that declares nothing keeps today's `raw/`-only contract unchanged.

## Context

The provenance model gives a page two channels and defines each by the object attributed. `sources:` holds sources the wiki captured under `raw/`, validated path by path; `## Derived from` holds "uncaptured external lineage" that is "**not** itself the subject of classification". Both rules sit under the **Cite each source in the channel its object calls for.** and **Record uncaptured external lineage under `## Derived from`.** lead-ins in [template_schema.md](../plugins/knowledge_management/skills/wiki/references/template_schema.md). A third object fits neither definition: a live in-repo document that *is* the subject of classification, a paper, spec, or codebase the wiki exists to explain, which the wiki deliberately does not snapshot because a `raw/` copy of an actively edited source goes stale on the next edit. Such a wiki wants the validation and structure of `sources:`, and it trades mechanical sha256 drift detection for a procedural coherence rule of its own.

The linter cannot express that trade. `check_source_paths_exist` in [lint.py](../plugins/knowledge_management/skills/wiki/scripts/lint.py) blocks any `sources:` entry that "escapes the wiki's `raw/` tree", and the acceptance store cannot clear it because acceptance reaches info findings only. The bound is stricter than the portability goal it serves. [wiki_lint-local-path-portability.md](archive/wiki_lint-local-path-portability.md) set out to stop machine-local paths from passing as provenance, and for the sibling field it chose the right boundary: a raw-sidecar `source_path:` "may point outside the wiki directory but must stay inside the repository", enforced by `check_source_path_portable` through `_git_repo_root`. For `sources:` it enforced the pre-existing "strict `raw/<kind>/<slug>.md` paths" wording instead, and [wiki_origin-field-contract.md](archive/wiki_origin-field-contract.md) later restated the two bounds side by side without a reason for the narrower one. A repo-relative `../paper/ch03.tex` resolves identically on every clone, so it meets the portability goal the rule exists for.

The agent compounds the gap. Its `<read_schema>` step captures only the type enum, custom fields, tag taxonomy, and domain statement; its `<configurable_zones>` lists no source-root declaration; and `<fix_external_source_pointer>` moves every `sources:` entry resolving outside `raw/` into `## Derived from` so the blocking finding "clears". Run on the wiki described above, an audit silently downgrades structured, validated citations into a prose section that receives no lint validation at all. In the motivating downstream wiki, whose repository is the paper it classifies, the earlier alignment audit left every such citation in place and recorded the migration as "a design decision left to the user", by judgment rather than by any guard.

The declaration mechanism this task adds follows the pattern [wiki_sanctioned-template-deviations.md](archive/wiki_sanctioned-template-deviations.md) freezes for locked slots: one labeled `## Lint` bullet, parsed by the fence-safe `iter_lint_section_lines` scan that `load_excluded_roots` and `LINT_ACCEPT_RE` share, honoured by linter and agent alike, and reported with a `(declared)` marker on the acknowledged channel outside the live totals. That task must ship first. It rewrites `<linter_is_truth_for_structure>`, `<inline_iteration_loop>`, and the `## Iteration loop` passage of [lint_checks.md](../plugins/knowledge_management/skills/wiki/references/lint_checks.md) to name three non-overlapping structural routes, and this task extends that enumeration to a fourth, so it edits those passages after they exist in their new form. [wiki_page-type-growth-and-anatomy.md](wiki_page-type-growth-and-anatomy.md) shares the SCHEMA `## Lint` / `<configurable_zones>` surface as a companion; compose `Declared source root:` additively with every `## Lint` sibling already present when this task ships. Two further live tasks share surfaces. [wiki_provenance-via-raw-and-sources.md](wiki_provenance-via-raw-and-sources.md) owns the capture rule and channel boundary inside the template's Provenance block, which this task widens by one object. [wiki_synthesis-citation-consistency-lint.md](wiki_synthesis-citation-consistency-lint.md) classifies an inline citation as a source by its `raw/` prefix; **Keep the downstream consumers coherent.** and its Out of scope deferral settle when this task widens that classifier and when that sibling owns later adoption.

## Approach

1. **Parse the declaration.** Add `load_declared_source_roots(wiki)` to `lint.py` beside `load_excluded_roots`. It reads `## Lint` through `iter_lint_section_lines`, matches the label `Declared source root:` case-insensitively, and left-anchors on ` — ` (the `ACCEPT_SEP` the acceptance bullets use) so the machine key is a wiki-root-relative path and the remainder is a free-text reason. Grammar, frozen: `- Declared source root: <path> — <reason>`, one bullet per root. A root may name a directory or a single file; a file root admits exactly that file. The reason is required and is never matched. Supersede the `iter_lint_section_lines` docstring in place so its machine-read-settings enumeration includes `Declared source root:` compose-additively with every setting already named there, leaving one canonical statement.

2. **Honour it in `check_source_paths_exist`.** Rewrite the check so a relative `sources:` entry passes when it resolves under `raw/` or under any declared root, and keeps today's behaviour otherwise: an entry resolving under neither stays the blocking `broken-source` "escapes" finding, and an entry under a declared root that resolves to no file is the blocking "missing on disk" finding, exactly as a `raw/` entry is. Bound the roots the way `check_source_path_portable` bounds `source_path:`. A declared root that resolves to no file or directory is itself a blocking `broken-source` finding on `SCHEMA.md`. When the wiki is inside a git repo, a declared root that resolves outside `_git_repo_root(wiki)` is likewise a blocking `broken-source` finding on `SCHEMA.md`, because it would legitimize non-portable entries. When the wiki is not inside a git repo it is local-only, so any root that resolves is accepted (the outside-repo gate does not apply). Report each valid declaration once on the acknowledged channel with the `(declared)` marker, naming the root and its reason, never as a live blocking, warn, or info Issue, through the acknowledged return path the sanctioned-template-deviations task wires. Rewrite relative-escape and SCHEMA root-validation `broken-source` messages so the remedy reads "use a `raw/…` path, or declare an in-repo root in `SCHEMA.md`". For absolute/`~`-prefixed blocking messages, rewrite the remedy in place to name rewriting the entry to a relative path under `raw/` or under a declared root — never imply that adding a `Declared source root:` bullet alone clears an absolute/`~` entry. The absolute-path safe-fix warn branch (resolves inside `raw/`) keeps today's portable `raw/…` rewrite. Supersede the function docstring in place so one statement of the widened contract remains. Also rewrite in place the `# Source-attribution checks` section comment and the `CANONICAL_FRONTMATTER` comment so each states the widened `sources:` contract (`raw/` or declared root) with prior `raw/`-only wording superseded. After the sanctioned-template-deviations prerequisite's three-source ACK wording exists, rewrite the module-docstring ACK paragraph, `Issue.render_acknowledged` docstring, `render_report` docstring, and `ACKNOWLEDGED` header so each names declared-source-root acknowledgements as a fourth acknowledged-channel source beside the three that prerequisite already wires, with the prior three-only passage superseded.

3. **Keep the downstream consumers coherent.** `check_stale_content` keys on `raw/` ingest dates and skips an entry it has no date for, and `check_quality_signals` counts entries regardless of root; confirm both hold for declared-root entries on the fixtures and adjust only if a fixture shows otherwise. When the synthesis-citation check already exists at implementation time, widen its citation classifier from a bare `raw/` prefix test to "resolves under `raw/` or under a declared root".

4. **Teach the agent.** In [auto_shaper_wiki.md](../plugins/knowledge_management/agents/auto_shaper_wiki.md): `<read_schema>` also captures the declared source roots; `<configurable_zones>` joins the `Declared source root:` bullets to every wiki-owned `## Lint` bullet already listed there (preserve all present siblings; replace none); `<external_source_pointer>` classifies a `sources:` entry or body `## Sources` bullet resolving under a declared root as a declared primary source, neither broken nor external by design; `<fix_external_source_pointer>` hoists body `## Sources` bullets that resolve under a declared root into `sources:` the same way it hoists `raw/`-resolvable inventory, leaves declared-root `sources:` entries untouched, and migrates only entries that resolve under neither `raw/` nor a declared root; rewrite `<fix_frontmatter_missing_or_malformed>` so writing `sources` admits citation under `raw/` or under a declared root, and leaves the key out only when the page cites neither; rewrite `<preserve_external_attribution>` so a `sources:` entry or body `## Sources` bullet resolving under a declared root is kept in / hoisted into frontmatter and is not treated as an outside-`raw/` migration case; rewrite `<provenance_violation>` and `<fix_provenance_violation>` so structured provenance admits inline path links that resolve under `raw/` or under a declared root, with page-level `sources:` as the inventory, superseding their prior `raw/`-only wording; `<linter_is_truth_for_structure>`, `<scaffold_alignment>`, and `<scaffold_alignment_is_in_scope>` name the declaration as a fourth non-overlapping structural route and add it to their preservation lists. A declared source root describes one wiki's repository layout, so `<verify_output>` does not report it as a candidate for the shipped template.

5. **Teach the skill and the references.** In [SKILL.md](../plugins/knowledge_management/skills/wiki/SKILL.md), rewrite the **Provenance** bullet and `<inline_iteration_loop>` in place so they name the fourth route and the third object. In `lint_checks.md`, rewrite in place to the widened contract the `frontmatter` table row so `sources` presence covers citation under `raw/` or under a declared root, the `broken-source` row, and the **blocking** line of `## Severity buckets`. Rewrite `## Iteration loop` in place so its three-route structural enumeration gains `Declared source root:` as a fourth non-overlapping structural route, with the prior three-route passage superseded. In `template_schema.md`, add a fenced `Declared source root:` example in `## Lint` alongside every fenced example already present in that section (preserve all; drop none), and rewrite the **Cite each source in the channel its object calls for.** and **Record uncaptured external lineage under `## Derived from`.** lead-in bullets so the object split reads: a source captured under `raw/`, cited in `sources:`; a live in-repo document that is the subject of classification, cited in `sources:` under a declared root, carrying no sha256 drift detection and relying on a coherence rule the wiki states; uncaptured lineage that is not the subject of classification, recorded in `## Derived from`. Also rewrite in place the three standing `raw/`-only restatements of that split — SKILL.md `<page_anatomy>` provenance passage, SKILL.md **External derivation** bullet, and `template_schema.md` Frontmatter ``Carry `sources:` `` passage — to the same three-object split. Compose the Provenance rewrite with the provenance task named in `## Context`, whichever lands second rewriting over the first.

6. **Prove it.** Layer 1 fixtures in [tests/wiki/layer1/run.sh](../tests/wiki/layer1/run.sh): a wiki inside a scratch git repo with a sibling directory outside the wiki, a declared root naming it, and a page citing a file under it lints with no `broken-source` finding and one `(declared)` acknowledged line; a fixture with one valid declared root and two pages each citing a file under that root lints with exactly one `(declared)` acknowledged line for that root (not one per page); the same page with the bullet removed draws the blocking "escapes" finding unchanged; a declared root resolving outside the scratch repo draws the blocking finding on `SCHEMA.md`; a wiki not inside a git repo with a resolving declared root accepts it with one `(declared)` acknowledged line, and the same wiki with a declared root resolving to nothing draws the blocking finding on `SCHEMA.md`; an entry under a declared root naming a missing file draws "missing on disk"; a file root admits only that file. A Layer 2 scenario in [tests/wiki/layer2/evals.json](../tests/wiki/layer2/evals.json): an audit of a wiki with a declared root leaves every declared-root `sources:` entry in frontmatter, creates no `## Derived from` bullet for them, and re-lints clean; and a body-bullet hoist case where a page whose body `## Sources` carries a bullet resolving under a declared root has that path hoisted into `sources:` frontmatter, creates no `## Derived from` bullet for it, and re-lints clean.

**Out of scope:**

- A new frontmatter field such as `primary_sources:` for the third object; the declared root carries the distinction with no new key.
- Widening the `raw/`-only default for a wiki that declares nothing.
- Migrating any downstream wiki's citations; each wiki declares its own roots.
- Adopting declared-root paths into the synthesis-citation classifier when that check does not yet exist at implementation time; [wiki_synthesis-citation-consistency-lint.md](wiki_synthesis-citation-consistency-lint.md) owns that widening when it ships.
