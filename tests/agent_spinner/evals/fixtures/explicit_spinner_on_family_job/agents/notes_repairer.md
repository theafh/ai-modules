- NOTES_CHECK_HEADINGS: heading levels increment by one.
- NOTES_CHECK_LINKS: every relative link resolves.
- NOTES_CHECK_PLACEHOLDERS: no TODO placeholder remains.

Write only the page you are assigned. Report the checks you ran and the repairs you made.
