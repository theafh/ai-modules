# FEATURES — Ledger Fixture

This file records what the fixture does today, grouped by the capability a user meets. A behaviour absent from this ledger is not part of the system as it stands, and the closing section lists what the repository declares but does not yet deliver.

## Greeting

- Running the command greets the named user as `hello, <name>`, and greets `world` when no name is given.
